# Registration-System
Secure user authentication system built with PHP, MySQL, HTML, and CSS. Features user registration, password hashing, login authentication, session management, protected dashboard access, logout functionality, and database integration using prepared statements for enhanced security.
# PHP Registration and Login System

A complete user authentication system developed using PHP, MySQL, HTML, and CSS.

## Features
- User Registration
- Secure Password Hashing
- User Login Authenticatio
- Session Management
- Protected Dashboard
- Logout Functionality
- Responsive User Interface
- MySQL Database Integration
- Prepared Statements for Security

## Technologies Used
- PHP
- MySQL
- HTML5
- CSS3

## Project Structure
├── db.php
├── register.html
├── register.php
├── login.html
├── login.php
├── dashboard.php
├── logout.php
└── style.css

## Setup
1. Create the MySQL database and users table.
2. Update database credentials in db.php.
3. Place the project in your web server directory.
4. Run register.html to create an account.
5. Login and access the dashboard.

## Security Features
- Password Hashing using password_hash()
- Password Verification using password_verify()
- Prepared Statements to prevent SQL Injection
- Session-based Authentication
